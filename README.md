# Bridge Bidder App

A mobile application designed.  
Author: **Huang Chen En**

---

## 📌 Overview
The **Bridge Bidder App** is a tool to simulate the bidding phase of the card game **Bridge**.  
It provides an interactive interface where users can manage boards, make bids, and practice bridge bidding strategies.

---

## 📂 Project Structure
- **Main Page**
  - Displays app name
  - Shows number of boards
  - Includes a **Start button** to begin

- **Bidding Page**
  - **Board Info:**  
    - Board number  
    - Vulnerability status  
    - Buttons: *Undo*, *Reset*
  - **Bidding Bar:**  
    - Bid spinner  
    - Pass/Double/Redouble spinner  
    - OK button  

- **Board Class & Constants**
  - Defines board information and core bidding constants

---

## 🎮 Features
- Start a new board for bidding practice  
- Track vulnerability and board numbers  
- Make bids using intuitive spinners  
- Undo or reset actions for corrections  
- Support for special actions (*Pass, Double, Redouble*)
